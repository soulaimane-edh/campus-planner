# Campus Planner
Application Web de gestion des enseignants, étudiants, modules, groupes TD/TP et emploi du temps (Spring Boot + Spring Data JPA + Thymeleaf).

## Démarrer
```bash
mvn spring-boot:run
```
- H2 en mémoire : `jdbc:h2:mem:campus` (console sur `/h2-console`).
- Comptes de démo :
  - admin@local / admin123 (ADMIN)
  - karim@local / teacher (TEACHER)
  - sara@local / student (STUDENT)

## Fonctionnalités couvertes
- Authentification simple par comptes (ADMIN, TEACHER, STUDENT) via formulaire de login.
- CRUD : enseignants, étudiants, groupes, modules.
- Assignation : responsable d'un module (enseignant), modules ↔ groupes (multi-sélection).
- Emploi du temps : création de séances (module, enseignant, groupe, salle, début/fin, type), suppression, affichage en timeline.
- Détection de conflits : salle, enseignant, groupe occupés sur le créneau + validation que l'enseignant/groupe sont affectés au module et que fin > début.
- Bonus : suivi & évaluation des étudiants (notes, type, remarques, date) via page dédiée.
- Données de démo auto-chargées (`DataInitializer`).

## Structure principale
- `src/main/java/com/example/campusplanner/model` : entités JPA (`UserAccount`, `Teacher`, `Student`, `GroupClass`, `ModuleCourse`, `SessionSlot`, `Role`).
- `repository` : JpaRepository par entité + requêtes de chevauchement pour les séances.
- `service/TimetableService` : détection de conflits et sauvegarde.
- `config` : `DataInitializer`.
- `controller` : vues Thymeleaf pour chaque domaine + planification.
- `templates` : pages Thymeleaf (dashboard, login, listes/formulaires, emploi du temps).

## Schéma de base de données (DDL simplifié)
```sql
create table users (
  id bigint generated by default as identity primary key,
  full_name varchar(255) not null,
  email varchar(255) not null unique,
  password varchar(255) not null,
  role varchar(20),
  active boolean
);

create table teacher (
  id bigint generated by default as identity primary key,
  first_name varchar(255) not null,
  last_name varchar(255) not null,
  email varchar(255) not null unique,
  specialty varchar(255),
  competencies varchar(255),
  workload_hours integer
);

create table group_class (
  id bigint generated by default as identity primary key,
  name varchar(255) not null,
  level varchar(255) not null,
  field_of_study varchar(255) not null
);

create table student (
  id bigint generated by default as identity primary key,
  first_name varchar(255) not null,
  last_name varchar(255) not null,
  email varchar(255) not null unique,
  field_of_study varchar(255) not null,
  level varchar(255) not null,
  competencies varchar(255),
  group_class_id bigint references group_class(id)
);

create table module_course (
  id bigint generated by default as identity primary key,
  code varchar(255) not null,
  name varchar(255) not null,
  field_of_study varchar(255) not null,
  semester varchar(50),
  volume_hours integer,
  required_competencies varchar(255),
  responsible_teacher_id bigint references teacher(id)
);

create table module_group (
  module_id bigint references module_course(id),
  group_id bigint references group_class(id)
);

create table session_slot (
  id bigint generated by default as identity primary key,
  room varchar(255) not null,
  session_type varchar(50),
  start_time timestamp,
  end_time timestamp,
  module_course_id bigint references module_course(id),
  teacher_id bigint references teacher(id),
  group_class_id bigint references group_class(id)
);

create table evaluation (
  id bigint generated by default as identity primary key,
  assessment_type varchar(255),
  grade double,
  evaluation_date date,
  remarks varchar(255),
  student_id bigint references student(id),
  module_course_id bigint references module_course(id)
);
```
